Radar de Ofertas

by Coin Afiliados — a private tool operated by a single person.

What it does

Radar de Ofertas collects public product catalog data from marketplace affiliate programs and organises it into a private dashboard, so its operator can decide which offers to promote as an affiliate.

  • Reads product catalogue data: title, price, discount, category, product image and link
  • Stores it in a private database on a self-hosted server
  • Presents it in a dashboard that only the operator accesses

What it does not do

  • It is not listed publicly and is not offered as a service to sellers
  • It does not read or store buyer data, orders, messages or personal data
  • It does not publish, post or send anything on any platform
  • It does not share collected data with third parties

Who operates it

A single operator, for their own affiliate activity. There are no other users and no customers.
