Privacy Policy

Radar de Ofertas, operated by Coin Afiliados. Last updated: 2026-08-07.

Personal data we collect

None. Radar de Ofertas does not collect, request, receive or store personal data of any person. It has no sign-up, no accounts and no visitors other than its operator.

What data the tool does handle

  • Product catalogue data published by marketplaces: title, price, discount, category, image and product link. This is commercial data about products, not about people.
  • Aggregate engagement counters that marketplaces publish next to a product, such as number of likes or units sold. These are totals, never individual behaviour.

Buyer, seller and creator data

The tool does not access orders, buyer information, addresses, payment data, messages, or any data identifying a seller's customers.

Where data is stored

On a private, self-hosted server controlled by the operator. It is not hosted with any third-party analytics or advertising provider, and it is not shared with anyone.

Credentials

API credentials are stored in a permission-restricted file on the server, never in source code, never in a public repository, and never transmitted to any third party.

Cookies and tracking

These pages set no cookies, load no external scripts and run no analytics.

Retention and deletion

Catalogue data is kept only while useful and can be deleted in full at any time by the operator. Since no personal data is collected, there are no data-subject requests to fulfil.
