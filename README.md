# coin-afiliados

Páginas públicas do **Radar de Ofertas**, ferramenta privada de uso próprio operada por
Coin Afiliados.

Existem porque plataformas de afiliado exigem URLs públicas de termos, privacidade e callback
de OAuth para aprovar um app.

| Página | Para quê |
|---|---|
| `index.html` | o que a ferramenta faz e o que não faz |
| `terms.html` | termos de uso |
| `privacy.html` | política de privacidade |
| `callback.html` | recebe o código de autorização do OAuth |

⚠️ **Este repositório é uma cópia.** A fonte vive no vault, em
`WORKSPACE/APPS/RADAR-OFERTAS/SITE_RADOF/`. Editar aqui cria divergência silenciosa —
mudou lá, republique.
